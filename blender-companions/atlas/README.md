# Atlas — editable V5 model

Atlas / Get stronger: fuzzy charcoal character with a sweeping #0097B2 band and sturdy friendly proportions.

Built from the user's selected `../../gym-ai-mascots-v5.png`. `atlas.blend` contains the larger rounded body, dense curled carpet geometry, sweeping turquoise band, editable separate limbs, and a neutral torso/head deformation rig. `atlas.glb` and `atlas.usdz` are portable exports; `atlas-preview.png` and `atlas-back.png` are still renders.

The band's colour feathers smoothly around the back and sides. Capsule eyes sit inside clear openings in the carpet pile, with shallow front relief matching the V5 face.

The detailed master is approximately two million triangles. `atlas-mobile.blend`, `.glb`, and `.usdz` retain fewer real carpet strands as a lighter integration candidate. No emotes, Actions, or animation clips were created. See `../review/MODELING_NOTES.md` for hierarchy, export and validation details. Physical iPhone performance remains to be checked.
