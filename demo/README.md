# Demo material

- Recorded clips used in the demo must be consented and labelled RECORDED in the UI. Raw clips are **git-ignored** (`demo/clips/`); commit a `clips.md` listing filename, person, exercise/variation, camera view, consent, and annotated rep count.
- Validation logs (`demo/logs/*.jsonl`) must come from the real pipeline. Fixture/mock output is marked `inference_provenance: "fixture"` and is never presented as a real result.
