# Gym&AI — silver Home concept

PNG design proposal only. Not approved for implementation. No Swift code changed for this proposal.

The first reference supplies a photo-led workout and clear hierarchy; the second supplies a cooler gray ground and softly translucent controls. The existing slate app palette is intentionally explored as a **light silver-gray** variant, preserving the teal `#0097B2` brand accent and charcoal text. SF Pro-style typography, spacious grouping, clear actions, and the two-tab navigation come from the requested `apple-hig` recipe.

Composition: compact logo/settings, welcoming heading, one workout photograph and exercise summary, a small Pip coaching area, camera/Watch setup shortcuts, a prominent Start workout action, then Today/Progress navigation. The sample set and rep target are labeled **Illustrative workout**. No heart-rate samples, calorie claims, progress percentages, or streaks are invented.

Used Impeccable and Web Design Engineer design guidance, adapted to the user's explicitly requested PNG deliverable. Apple describes Liquid Glass as a layer for controls and navigation over content: [Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials). This concept expresses that distinction through glass controls and stable workout content. Exact implementation metrics, Dynamic Type layouts, accessibility contrast, and reduce-transparency variants would be validated when the design is selected.

The image generator approximates the logo artwork; implementation must use the original supplied logo asset rather than the generated lettering. The workout photo is generated concept imagery. Pip references the existing `PipPreview` asset.

Assets: [PNG concept](home-silver-concept-v1.png), [exact generation and edit prompts](home-silver-concept-v1.png.json). Built-in ImageGen produced the image; one targeted edit corrected the device labels. Review checked text, control separation, complete navigation, and uncluttered hierarchy.
